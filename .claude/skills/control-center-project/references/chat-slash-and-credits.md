# Chat slash commands and /credits

- Slash commands are client side (apps/web/src/chat/slash.ts). Hermes plugin commands (/credits, /llama, /pc) are NOT run by the Hermes API; sent as text they reach the model, which costs tokens and may improvise. Do not forward them. The same goes for Pi's own terminal commands: `/reload` sent over RPC is just text to the model (see `pi-backend.md`, "Skills").
- Shared `COMMANDS`: new, model, reasoning, stop, retry, title, export, pin, archive, delete, steer, credits, usage, help. `PI_COMMANDS` exist only in Pi chats: login (opens the sign-in sheet), yolo (toggles the chat's server-side auto-approve). `/compact` was removed: manual compaction and the auto-compaction toggle live in the Pi options sheet. The threshold is fixed in the bridge (256k trigger, 51,200 kept), not a setting.
- Page commands (retry, title, export, pin, archive, delete, steer, credits, usage, login, yolo) run in `runAction` in Chat.tsx; composer-only: new, model, reasoning, stop, help. `/new` takes an optional agent: `/new hermes`, `/new pi`.
- Every command's result is saved as a row in the thread (`chat-ui.md`, "Command rows are saved"). `onAction` records whatever `runAction` returns; return "" to record nothing (login does, because it opens a sheet).
- Add a command = a `COMMANDS` (or `PI_COMMANDS`) entry + `PAGE_COMMANDS` + a `runAction` branch + tests. `slash.test.ts` pins the full suggestion list, so adding one fails it until the list is updated. Unknown/help text is generated from the lists.
- /credits: GET /api/chat/credits -> host service `credits-http.service` (systemd --user, ~/.local/bin/credits-http, 127.0.0.1:9103, read-only, 30s cache, runs `credits --discord` with `CREDITS_SKIP_CODEX=1` (no OpenAI block, faster), the same markdown otherwise the Discord plugin sends; the web renders it with `creditsMarkdown` in `chat/credits.ts`). CC reaches it because the container is network_mode host; override with CREDITS_URL. Down = 502 'credits service is not reachable'.
- /pc and /llama deliberately not in chat (power control by free text); use the unit page buttons.
